# Artur Platform GitOps

This repository is the deployment source of truth for the Artur Platform MVP.
Argo CD runs in a local kind cluster, watches this public repository, and deploys
platform observability plus services generated by Backstage.

## Layout

- `applications/` contains child Argo CD Applications.
- `platform/observability/` contains Prometheus and OpenTelemetry Collector resources.
- `services/` is populated by the Backstage Go service template.
- `bootstrap/root-application.yaml` is the app-of-apps entry point.
- `kind/cluster.yaml` provides the reproducible local cluster.

## Bootstrap

Prerequisites: Docker, `kind`, and `kubectl`.

```bash
./scripts/bootstrap.sh
./scripts/port-forward.sh
```

Open Argo CD at <https://localhost:8080> and Prometheus at
<http://localhost:9090>. Retrieve the initial Argo CD password with:

```bash
kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath='{.data.password}' | base64 --decode
```

## Generated services

Backstage opens a same-repository branch and pull request containing an Argo CD
Application and a small Helm deployment chart. The
`Validate and merge Backstage GitOps updates` workflow only accepts branches
whose name starts with `backstage/` and whose head repository is this repository.
It validates YAML and Helm output before merging. The write-capable merge job
never checks out pull-request content.

Service images use immutable commit SHA tags in GHCR. If an organization policy
creates the first package as private, change that package's visibility to public
once so kind can pull it without a registry secret.
